# environments/

`registry.yaml` holds the environment and site codes used to derive each site's
`distributed-system-id` (`ENV x 10 + SITE`: prod/primary = 11, prod/dr = 12,
dev/primary = 21, dev/dr = 22, ...).

No application configuration lives here. Application settings come from
`gemfire-application-config`; per-site identity is generated by
`scripts/generate-site-identity.sh` and contains only the top-level key `site:`.

Adding an application requires no change in this directory. Adding an environment
(for example `stg`) only requires a code in `registry.yaml` and a matching
cert-manager issuer named `gemfire-<env>-ca`.
